# ADR 0001: Separate moderation service

## Status
Proposed

## Context
Нужно встроить модерацию в продукт (Mini App backend + Telegram bot) и при этом выполнить требования модуля по сервису, CI/CD, мониторингу и версионированию артефактов.

## Decision
Выделяем модерацию в отдельный сервис (`moderation-service`) с REST API.

## Consequences
Плюсы:
- чёткие границы ответственности
- независимый деплой и масштабирование
- единая точка аудита и мониторинга качества LLM

Минусы:
- дополнительная сеть/латентность
- нужно продумывать fallback при недоступности сервиса/LLM
